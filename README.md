# Product Description Generator

AI-powered tool that generates marketing copy for e-commerce products.

## What It Does
Generates professional, casual, or luxury product descriptions using 
few-shot prompt engineering with Qwen2.5-7B-Instruct via the 
Hugging Face Inference API.

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Set your HF token: `export HF_TOKEN=your_token`
4. Run: `streamlit run app.py`
